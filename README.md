# APA 8-Ball Lineup Planner

Plan legal APA 8-ball lineups under the 23-point skill level cap.

**Live:** https://thadrazdow.github.io/apa-lineup-planner/

- Tap a skill level to change it (SL 2–7).
- Drag or tap each slider: **In** (definitely playing), **Maybe**, or **Out**.
- Every legal 5-player lineup is listed, highest total first.

Single static `index.html` — no build step.
